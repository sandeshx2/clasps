# Clasps

Click the toolbar icon to copy a ready-to-run download command for the current tab.

- Normal pages → `yt-dlp` command (1080p default)
- Spotify tracks/albums/playlists → `spotdl` command (M4A default)

![Clasps icon](icons/icon-128.png)

## What you need

- [`yt-dlp`](https://github.com/yt-dlp/yt-dlp) and/or [`spotDL`](https://github.com/spotDL/spotify-downloader) installed

## Install

1. Open `chrome://extensions`, enable **Developer mode**
2. Click **Load unpacked** and select this folder
3. Pin Clasps, click it on any media page, paste the command in a terminal

Right-click the icon → **Clasps settings** to change quality, format, filename, and folder (defaults to your Downloads folder).

Only download media you have permission to access.
